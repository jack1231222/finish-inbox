# FinishInbox 0.1.0-preview.1

> Technical preview: the downloadable app is ad-hoc signed and has not been
> notarized by Apple. Building from source is recommended.

This first public preview provides:

- persistent unread completion counts by private project label;
- explicit local events for Codex, Claude Code, and shell hooks;
- duplicate-event protection with a bounded seven-day / 10,000-ID window;
- project-isolated clear behavior and restart persistence;
- private `0700` directories and `0600` config, state, queue, and lock files;
- universal `arm64` + `x86_64` builds targeting macOS 13 or later;
- source install, uninstall, archive checksum, and source-revision manifest.

The archive includes `FinishInbox.app`, a separately signed `finish-inbox` CLI,
and the installer. Download the ZIP and matching `.sha256` file into one folder,
then verify:

```bash
shasum -a 256 -c FinishInbox-v0.1.0-preview.1.zip.sha256
```

Downloaded builds may require explicit approval under **System Settings →
Privacy & Security**. The installer does not remove quarantine attributes or
weaken Gatekeeper.

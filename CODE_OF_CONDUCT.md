# Code of Conduct

Be direct, respectful, and specific.

- Discuss the code or behavior, not the person.
- Make room for maintainers and contributors with different experience levels.
- Do not publish another person's private paths, logs, task text, or identity.
- Stop harassment, threats, sexualized conduct, and discriminatory language.

Maintainers may edit or remove content, close contributions, or restrict
participation when needed to protect the project and its contributors.

For conduct concerns, use a private contact method on the maintainer's GitHub
profile rather than a public issue.

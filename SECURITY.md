# Security Policy

## Supported versions

Only the latest published preview or stable release receives fixes.

## Reporting

Please use GitHub's private vulnerability reporting feature for this repository.
Do not open a public issue containing private paths, local state, event files,
or proof-of-concept code that exposes user data.

Include:

- the affected version and macOS version;
- the smallest redacted reproduction;
- expected and observed behavior;
- whether another local account, a downloaded artifact, or an integration hook
  is involved.

Never include API keys, prompts, model responses, or complete config/state
files.
